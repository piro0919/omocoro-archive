# Omocoro Archive

> Unofficial archive site for [Omocoro](https://omocoro.jp/). Search and browse articles as a PWA.

[🔗 Live Site](https://omocoro-archive.kkweb.io/)

## ✨ Features

- 🔍 Full-text article search
- 📖 Browse archived articles offline
- 📱 Installable PWA
- 🤖 Android app (APK) built as a Trusted Web Activity
- ⚡ Server-side rendering for fast loads

## 🤖 Android

Download `app-release-signed.apk` from [Releases](https://github.com/piro0919/omocoro-archive/releases/latest) and open it on your device. Android 7.0 or later is required, and you need to allow installs from unknown sources.

The app opens the live site in Chrome without the address bar. It is generated by [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) from `android/twa-manifest.json`, and `public/.well-known/assetlinks.json` holds the signing key fingerprint that links the site to the app.

To build a new version, bump `appVersionCode` and `appVersionName` in `android/twa-manifest.json`, then run:

```bash
cd android
npx @bubblewrap/cli update --skipVersionUpgrade
npx @bubblewrap/cli build
```

The signing key is kept outside the repository. Building with a different key breaks updates for existing installs and the assetlinks check.

## 🛠 Tech Stack

- **Frontend**: Next.js 15 (App Router) + React 19
- **Database**: PostgreSQL + Prisma ORM
- **Styling**: CSS Modules
- **PWA**: Serwist (Service Worker)
- **Deployment**: Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js 20+
- Docker & Docker Compose

### Setup

```bash
npm install
cp .env.local.example .env.local
# edit .env.local with DATABASE_URL
npm run db:migrate
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
